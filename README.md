# StudyFlow

Created by Roshan.

This project is a full-stack, offline-capable study planning and productivity application built with vanilla HTML, CSS, and JavaScript.

## Overview

StudyFlow is designed to be a comprehensive tool for students and learners to organize their schedules, manage tasks, set goals, and track their progress. It features a modern, responsive interface and is built to work seamlessly even without an internet connection by storing all data locally in the browser.

## Features

-   **Planner:** A dynamic monthly calendar to schedule and view events.
-   **Tasks:** A comprehensive to-do list for managing tasks, sortable by due date.
-   **Goals:** A dedicated screen to set and save short-term and long-term goals.
-   **Goal-to-Task Workflow:** An integrated feature to break down large goals into actionable tasks.
-   **Progress Tracking:** A visual dashboard with dynamic charts to track completed tasks and time spent over different periods.
-   **Focus Timer:** A Pomodoro-style timer to help with focused study sessions.
-   **Soundscapes:** A library of ambient sounds to play during focus sessions to minimize distractions.
-   **Offline-First:** All data is saved locally in IndexedDB, so the app is fully functional offline.
-   **Notifications:** The app provides browser notifications for alerts (e.g., when a focus session ends) and non-intrusive "toast" messages for feedback (e.g., "Goal saved!").

## How to Run

Since this is a client-side application, no build steps are required.

1.  Clone or download the repository.
2.  Open the `planner.html` file in any modern web browser (like Chrome, Firefox, or Edge).

The application will start, with the Planner screen as the default view.
